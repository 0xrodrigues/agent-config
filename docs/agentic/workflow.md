# Workflow agentic

## Estados

`refinamento` → `investigação` → `planejamento` → `aguardando aprovação` → `implementação` → `revisão` → `concluído`

O trabalho pode retornar para uma etapa anterior quando surgirem novas evidências. A implementação só começa após a aprovação exigida pelo contexto.

## Artefato por tarefa

Crie uma pasta em `work/tasks/<identificador>/` com `contexto.md`, `plano.md`, `evidencias.md` e `resultado.md` quando a tarefa justificar rastreabilidade. Mantenha apenas informações não sensíveis.

## Handoff

Todo handoff deve informar: objetivo, estado atual, evidências, decisão tomada, próximo passo, bloqueios e validações executadas.
