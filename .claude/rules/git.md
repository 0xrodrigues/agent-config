# Git

- Confirme que o diretório é um worktree antes de depender de comandos Git para validação.
- Preserve alterações existentes do usuário; não use `reset --hard`, checkout destrutivo ou limpeza ampla sem autorização explícita.
- Mantenha commits focados, com mensagem que descreva a intenção.
- Não altere submódulos, branches remotos, tags ou configuração de repositório sem pedido explícito.
- Execute verificações proporcionais ao risco antes de propor commit ou pull request.
