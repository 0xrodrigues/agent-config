# Testing

Planeje testes a partir dos critérios de aceite e do risco da alteração.

1. Cubra caminho principal, validações, falhas e integrações afetadas.
2. Preserve testes existentes e prefira testes determinísticos.
3. Execute a menor suíte suficiente e amplie conforme o impacto.
4. Reporte cobertura real, comandos e lacunas; sucesso sem testes não é evidência forte.
