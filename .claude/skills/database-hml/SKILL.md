# Database HML

Use somente para investigação e validação em homologação autorizada.

1. Confirme ambiente, banco, esquema e autorização.
2. Prefira consultas de leitura, limitadas e com filtros.
3. Não copie dados pessoais para arquivos locais ou documentação.
4. Para escrita, apresente o comando, o alvo, o impacto e o plano de reversão antes da execução.
