# Java build

Use a ferramenta de build já adotada pelo serviço.

1. Leia os arquivos de build e a versão de Java requerida.
2. Execute primeiro a validação mais específica e depois a suíte relevante.
3. Informe comandos executados, resultado e limitações, como ausência de testes descobertos.
4. Não atualize plugins ou dependências apenas para fazer uma compilação passar sem análise de impacto.
