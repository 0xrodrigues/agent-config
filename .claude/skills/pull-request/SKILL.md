# Pull request

Prepare uma revisão legível e verificável.

1. Confirme o diff, escopo, testes e documentação antes de abrir a solicitação.
2. Descreva problema, solução, impacto, validação e riscos conhecidos.
3. Vincule a tarefa rastreável quando existir.
4. Não abra, aprove ou faça merge de pull request sem autorização explícita.
