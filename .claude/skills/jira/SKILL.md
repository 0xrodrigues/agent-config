# Jira

Use para consultar ou preparar trabalho rastreável.

1. Confirme chave, projeto e permissão antes de criar ou alterar itens.
2. Resuma contexto, objetivo, critérios de aceite, dependências e risco.
3. Nunca publique comentários, transições ou tickets sem solicitação explícita.
4. Registre o link ou a chave nos artefatos da tarefa, sem copiar dados sensíveis.
